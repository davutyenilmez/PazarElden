# PazarElden
Türkiye odaklı ikinci el ilan platformu.

## Kurulum
1. `config.js` dosyasına Supabase Project URL ve **anon/publishable** key ekleyin.
2. Dosyaları GitHub reposuna yükleyin.
3. Vercel/Netlify gibi statik hosting ile yayınlayın.

> `service_role` anahtarını istemci tarafına asla eklemeyin.
